# Português Quest 🇵🇹

A cozy, gamified way to learn **European Portuguese** — by exploring Portugal one little
adventure at a time.

> Work in progress. See [docs/ROADMAP.md](docs/ROADMAP.md) for progress and
> [docs/VISION.md](docs/VISION.md) for the product direction.

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## Stack
React · TypeScript · Vite · Tailwind CSS · React Router · Framer Motion · Lucide.
Progress is stored locally for now; Supabase integration is planned.
